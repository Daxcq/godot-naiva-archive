**本次做的事**

2. 发现 `addons/godot_mcp/` 插件写好了但**从未在 `project.godot` 里启用** —— 补上 `[editor_plugins] enabled=PackedStringArray("res://addons/godot_mcp/plugin.cfg")`。

5. 写入 `~/.workbuddy/mcp.json`，新增 `godotMCP`（保留原有 `unityMCP`）。command 用 `C:\Program Files\python\python.exe`（系统 3.8.6，路径稳定）。
6. README 补"编辑器 MCP 接入"章节：启用方式、端口占用说明、配置文件、使用顺序。

**关键结论 / 坑**
- 端口不冲突：插件 TCP **6400 只在 Godot 编辑器进程内监听**；运行时视觉链路用 UDP 6401/6402，游戏运行时不占 6400。不要误以为是资源冲突。
- 插件确实能正常加载：`--headless --editor --path . --quit-after 30` 会打印 `Godot MCP Plugin activated` / `listening on port 6400`。注意 `--quit-after` 是**帧数不是秒**，所以脚本里靠 OS-level 轮询 6400 端口会误判"插件没启用"——验证要以编辑器 stdout 为准。
- **使用前提：必须先让 Godot 编辑器打开本工程并保持运行**，MCP 才有连接对象。仅启动编辑器不够——插件要启用。
