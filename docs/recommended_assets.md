## ⚖️ 许可协议快速指南

### CC0 (Public Domain)
- ✅ 完全免费商用
- ✅ 无需署名
- ✅ 可修改
- **最佳选择**

### CC-BY (Attribution)
- ✅ 免费商用
- ⚠️ 需要署名作者
- ✅ 可修改

### Free Personal Use
- ✅ 个人/学习项目免费
- ❌ 商业使用需购买许可
- 适合原型开发

### Royalty Free
- ✅ 一次购买永久使用
- ✅ 商用无版税
- 💰 需要初始费用

## 🛠️ 下载与处理工作流

### 工作流示例 (以街机为例)

1. **下载模型**
   ```
   访问: https://sketchfab.com/3d-models/arcade-cabinet-glb-v09-free-low-poly-...
   点击 Download 3D Model
   选择格式: glTF (GLB) 
   保存到: D:\桌面\raw_assets\arcade_cabinet_raw.glb
   ```

2. **导入 Blender**
   ```
   Blender > File > Import > glTF 2.0 (.glb/.gltf)
   选择文件: arcade_cabinet_raw.glb
   ```

3. **检查与优化**
   ```python
   # 在 Blender 中运行 (Scripting 工作区)
   import bpy
   obj = bpy.context.active_object
   print(f"面数: {len(obj.data.polygons)}")
   # 如果超过 25k 面,添加 Decimate 修改器
   ```

4. **调整材质为霓虹风格**
   ```
   Shading 工作区 > 
   Principled BSDF > 
   - Emission 颜色: #00FFFF (青色) 或 #FF00FF (品红)
   - Emission 强度: 3.0
   ```

5. **导出到项目**
   ```
   File > Export > glTF 2.0
   格式: GLB
   Transform: +Y Up ✓
   保存到: D:\桌面\godot-naiva-archive\assets\environment\arcade_snake.glb
   ```

6. **Godot 导入**
   ```powershell
   cd "D:\桌面\godot-naiva-archive"
   godot --headless --path . --import --quit-after 200
   ```

## 🆘 常见问题

### Q: Sketchfab 下载需要登录吗?
**A**: 是的,但免费账号即可下载大部分 CC 授权模型。

### Q: GLB 和 FBX 选哪个?
**A**: 优先 GLB/GLTF,Godot 原生支持更好,贴图自动内嵌。

### Q: 如何判断许可是否允许商用?
**A**: 
- Sketchfab: 下载页面显示许可类型
- 搜索 CC0 / CC-BY 标签最安全
- 有疑问时联系作者确认

### Q: 模型太大怎么办?
**A**: Blender Decimate 修改器,Ratio 设为 0.3-0.5,应用后重新导出。

### Q: 如何快速测试霓虹效果?
**A**: Godot 中添加 OmniLight3D,颜色设为青色/品红,能量值 3-5,开启阴影。
