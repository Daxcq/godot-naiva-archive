## 🔍 下载步骤

### OpenGameArt 下载

1. 访问链接（如 https://opengameart.org/content/gritty-lowres-scifi-wall-and-floor-textures）
2. 页面右侧找到 "Download" 按钮
3. 无需登录，直接下载 ZIP
4. 解压到 `D:\桌面\raw_textures\game_textures\scifi_floor\`

### itch.io 下载

1. 访问链接（如搜索结果页面 https://itch.io/game-assets/free/tag-cyberpunk/tag-materials）
2. 找到 "8K CyberPunk panel Pack Vol. 1 [CC0]"
3. 点击进入详情页
4. 点击 "Download Now"（可能需要免费 itch.io 账号）
5. 输入 $0 或任意金额（如果支持付费）
6. 下载并解压
