## 🛠️ Godot 材质设置指南

### 标准 PBR 材质设置

在 Godot 中创建 `StandardMaterial3D`:

```gdscript
# 档案馆混凝土地板材质
var floor_material = StandardMaterial3D.new()

# 基础颜色贴图
floor_material.albedo_texture = preload("res://assets/textures/concrete_floor_albedo.png")
floor_material.albedo_color = Color(0.16, 0.16, 0.16, 1.0)  # 深灰底色

# 法线贴图(凹凸细节)
floor_material.normal_enabled = true
floor_material.normal_texture = preload("res://assets/textures/concrete_floor_normal.png")
floor_material.normal_scale = 1.0

# 粗糙度贴图(反光程度)
floor_material.roughness_texture = preload("res://assets/textures/concrete_floor_roughness.png")
floor_material.roughness = 0.8  # 0=镜面, 1=完全粗糙

# 金属度
floor_material.metallic = 0.0  # 混凝土不是金属
floor_material.metallic_texture = preload("res://assets/textures/concrete_floor_metallic.png")

# 环境光遮蔽(AO)
floor_material.ao_enabled = true
floor_material.ao_texture = preload("res://assets/textures/concrete_floor_ao.png")
floor_material.ao_light_affect = 0.5

# UV 缩放(平铺)
floor_material.uv1_scale = Vector3(4, 4, 1)  # 地板重复 4x4 次
```

### 霓虹发光墙壁材质

## 🔄 工作流程

### 1. 下载材质 (以 Poly Haven 为例)

```powershell
# 访问 Poly Haven
# 选择材质,如: Concrete Floor 001
# 下载选项:
#   - Resolution: 4K (4096x4096)
#   - Maps: All (Diffuse/Displacement/Normal/Roughness/AO)
#   - Format: PNG
# 保存到: D:\桌面\raw_textures\concrete_floor_001\
```

### 2. 整理到项目

```
D:\桌面\godot-naiva-archive\
  assets\
    textures\
      floors\
        concrete_001\
          concrete_001_albedo.png      # 重命名为统一格式
          concrete_001_normal.png
          concrete_001_roughness.png
          concrete_001_ao.png
          concrete_001_displacement.png
      walls\
        concrete_wall_001\
          concrete_wall_001_albedo.png
          concrete_wall_001_normal.png
          ...
      metal\
        brushed_metal\
          ...
```

### 3. 导入 Godot

Godot 会自动生成 `.import` 文件。检查导入设置:

```ini
[remap]
importer="texture"
type="CompressedTexture2D"

[params]
compress/mode=2        # VRAM 压缩
compress/high_quality=true
compress/lossy_quality=0.7
compress/hdr_compression=1
compress/normal_map=0  # Normal 贴图设为 1
mipmaps/generate=true  # 生成 Mipmap(远处纹理模糊,减少锯齿)
mipmaps/limit=-1
process/size_limit=0
detect_3d/compress_to=0
```

**重要**: Normal 贴图的 `.import` 文件中 `compress/normal_map=1`

### 4. 创建 Godot 材质资源

在 Godot 编辑器中:
1. 右键 `assets/materials/` → New Resource → StandardMaterial3D
2. 命名: `floor_concrete_001.tres`
3. 在 Inspector 中设置各项贴图
4. 保存材质资源

### 5. 应用到场景

```gdscript
# 在场景脚本中
@onready var floor_mesh = $FloorMeshInstance3D
var floor_material = preload("res://assets/materials/floor_concrete_001.tres")

func _ready():
    floor_mesh.material_override = floor_material
```

或直接在编辑器中拖拽材质到 MeshInstance3D 的 Material 槽。

## ⚙️ 性能优化

### UV 平铺而非大贴图

```gdscript
# 地板 20m x 20m,使用 2K 贴图重复 10 次
material.uv1_scale = Vector3(10, 10, 1)
# 而不是使用 20K 巨型贴图覆盖整个地面
```

### Mipmap 必须开启

- 远处纹理自动降低分辨率
- 防止摩尔纹和闪烁
- Godot 默认开启,检查 `.import` 文件

### 压缩格式

- **Albedo/Emission**: VRAM Compressed (compress/mode=2)
- **Normal**: VRAM Compressed + Normal Map Flag
- **Roughness/Metallic**: 可用单通道压缩(compress/mode=1)

### LOD 材质

远处物体使用简化材质(无 Normal/AO,降低分辨率)。

## 🎨 材质混合技巧

### 叠加霓虹效果到现有墙壁

```gdscript
# Shader 混合基础墙壁 + 霓虹发光
shader_type spatial;

uniform sampler2D wall_albedo : source_color;
uniform sampler2D wall_normal : hint_normal;
uniform sampler2D neon_mask : source_color;
uniform vec3 neon_color : source_color = vec3(0.0, 1.0, 1.0);  // 青色
uniform float neon_intensity : hint_range(0.0, 10.0) = 3.0;

void fragment() {
    // 基础墙壁颜色
    vec4 base = texture(wall_albedo, UV);
    ALBEDO = base.rgb;
    
    // 法线
    NORMAL_MAP = texture(wall_normal, UV).rgb;
    
    // 霓虹发光遮罩
    float mask = texture(neon_mask, UV).r;
    EMISSION = neon_color * mask * neon_intensity;
}
```

### 程序化磨损效果

```gdscript
# 添加随机磨损到金属表面
uniform float wear_amount : hint_range(0.0, 1.0) = 0.3;

void fragment() {
    float noise = fract(sin(dot(UV, vec2(12.9898, 78.233))) * 43758.5453);
    float wear = smoothstep(1.0 - wear_amount, 1.0, noise);
    
    ROUGHNESS = mix(base_roughness, 1.0, wear);  // 磨损区域更粗糙
    METALLIC = mix(base_metallic, 0.2, wear);    // 磨损区域失去金属感
}
```

## 🆘 常见问题

### Q: 贴图导入后显示为粉红色?
**A**: 
1. 检查 `.import` 文件是否正确生成
2. 重新导入: 右键贴图 → Reimport
3. 确认贴图路径正确

### Q: Normal 贴图没有凹凸效果?
**A**:
1. `.import` 文件中 `compress/normal_map=1`
2. 材质中 `normal_enabled = true`
3. 场景中有光源(无光看不出凹凸)

### Q: 地板太亮/太暗?
**A**: 调整材质 `albedo_color` 的亮度分量,或在场景中添加适当光照。

### Q: 纹理看起来模糊/有锯齿?
**A**:
1. 开启 Mipmaps: `.import` 中 `mipmaps/generate=true`
2. 提高贴图分辨率
3. 检查 UV 缩放是否过大

### Q: 霓虹不够亮?
**A**: 提高 `emission_energy_multiplier` 到 5-10,或添加 `WorldEnvironment` 中的 `Glow` 效果。
